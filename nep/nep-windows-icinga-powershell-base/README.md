- For Install IcingaForWindows the server should be have access to Internet

The plugins user guide is on: [https://github.com/Icinga/icinga-powershell-plugins/blob/master/doc/10-Icinga-Plugins.md](https://github.com/Icinga/icinga-powershell-plugins/blob/master/doc/10-Icinga-Plugins.md)
